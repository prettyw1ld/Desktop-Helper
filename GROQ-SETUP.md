# Groq

Добавлена интеграция Groq для зрения, текстового чата и упрощения объяснений. Модель по умолчанию: qwen/qwen3.8-27b. Для голоса используется whisper-large-v3.

Настройки команды: provider="groq", groqModel="qwen/qwen3.8-27b", groqKey="ваш ключ". Не публикуйте заполненный team.json. Приложение также может использовать sttKey, если sttUrl указывает на Groq. Личные ключи сохраняются средствами safeStorage вне исходников.

Изображения передаются в память запроса как JPEG/base64. Зрение запрашивает JSON с прежней структурой результата; клавиатура и мышь остаются под контролем пользователя. Ошибки авторизации, лимитов и некорректного ответа показываются пользователю.

Проверено реальным API: текстовый запрос и распознавание заголовка «Загрузки» на тестовом изображении. Проверены браузерные сценарии на тестовом API. Точность координат и прохождение реального рабочего стола нужно проверить отдельно.
