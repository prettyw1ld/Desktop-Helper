# Помощь с файлами на macOS

В главном меню кнопка «Помоги с файлами» заменяет «Посмотреть фото с флешки». Фото с флешки остаются внутри нового меню. Собственные кнопки в настройках сохраняются; старая кнопка «Посмотреть фото с флешки» также открывает новое меню.

## Что проверить

Запустить `npm start` (на Mac перед запуском автоматически собирается небольшой нативный помощник; для новой копии исходников нужны Command Line Tools со Swift), нажать на кота → «Помоги с файлами».

1. **Научиться работать с папками.** Откроется Finder с учебной папкой в каталоге данных Пушика. Шесть шагов: открыть «Мои открытки», вернуться назад, открыть письмо, вернуться к папке, включить поиск, найти письмо. Папка содержит только примеры; повторный запуск сохраняет изменения в них.
2. **Найти скачанный файл.** Открывается настоящая папка «Загрузки», затем подсказки по поиску и открытию. Последний результат подтверждает человек.
3. **Открыть свой документ.** Обычный системный выбор файла. Отмена не открывает ничего и не записывает навык.
4. **Посмотреть фото с флешки.** Существующий сценарий.

Подсветка читает элементы напрямую через Accessibility API macOS, без ИИ, снимков экрана и медленного обхода System Events. Маленькие служебные окна macOS отбрасываются; имена файлов в виде «список» распознаются как текстовые поля. Переходы проверяются по первому настоящему окну Finder независимо от фокуса Пушика. Нужен «Универсальный доступ» для Пушика (при запуске из исходников приложение может называться Electron). Основному поиску не нужно разрешение «Автоматизация»; резервный поиск и прежние сценарии могут запросить доступ к System Events. Приложение не включает разрешения самостоятельно. Если доступа нет, меню объясняет, как открыть настройки и проверить снова.

Нужные кнопки ищутся по русским и английским названиям в первом окне Finder. Если боковая панель или панель инструментов скрыта, подсветки может не быть: подсказка остаётся, доступны повтор и «Не получилось». Для поиска есть запасное сочетание ⌘F, для возврата — ⌘[. Условия перехода между учебными папками проверяют Finder и заголовок окна. Открытие документа и результат поиска можно подтвердить вручную; это не автоматическая проверка содержимого файла.

Новые обучающие сценарии доступны на Mac. На Windows меню, системный выбор документа и прежний сценарий флешки работают, а обучение и «Загрузки» показывают сообщение о доступности на Mac.

## Проверки разработки

`node --test tools/test-file-help.js`

Проверяются условия перехода, защита от двойного завершения шага, отмена отложенных операций, маршрутизация запросов, сохранность учебных файлов и отмена выбора документа. Это проверки с подменой системного окружения; они не подтверждают положение рамок на реальном Finder.

Нативный помощник собирается из `src/native/locator.swift` в `assets/mac/locator-<архитектура>` при `npm start` и сборке приложения. В готовом приложении компилятор не нужен. Папка с помощником исключается из ASAR-упаковки. Если его нет, используется исправленный резервный JXA-поиск.

Подсказка пересчитывает своё положение при движении кота и остаётся внутри экрана. Длинные инструкции прокручиваются. Перенос кота во время обучения сохраняет текущий шаг и оставляет его в выбранном месте; подсветка остаётся на нужном элементе.
