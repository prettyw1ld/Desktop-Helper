# Архитектурные решения (ADR)

Короткие записи о решениях, которые трудно отменить или о которых будут спрашивать: что решили, почему и чем за это платим. Формат: контекст, решение, рассмотренные варианты, последствия.

|---|---|---|

| [0002](0002-no-agent-actions.md) | Пушик ничего не делает за человека: без инструментов и автонажатий | принято |
| [0003](0003-local-checks-before-ai.md) | Что можно проверить на ПК, проверяем до запроса к ИИ | принято |

Источники лучших практик собраны в исследовании «Лучшие практики корпоративного Пушика» (папка проекта, не в репозитории).
