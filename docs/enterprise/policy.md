# Политика организации (корпоративный режим)

Если на компьютере есть политика, Пушик работает в корпоративном режиме:

- ИИ обращается только к серверу из политики; запросы на любой другой адрес блокируются в самом приложении;
- облачные сервисы (Groq, Claude, DeepSeek, Qwen) и их ключи не используются, `team.json` не читается;
- раздел «Помощник с ИИ» в настройках скрыт, пользователь модель и ключ не меняет;
- голос распознаётся только на самом компьютере (Vosk);
- испорченная политика выключает ИИ целиком, а не возвращает облако.

Без политики Пушик работает как раньше.

## Файл

| Система | Путь |
|---|---|
| Windows | `%ProgramData%\Pushik\policy.json` |
| macOS | `/Library/Application Support/Pushik/policy.json` |

Писать в эти папки может только администратор.

```json
{
  "org": "Отдел ИБ",
  "ai": {
    "kind": "openai",
    "url": "https://llm.corp.local/v1",
    "model": "qwen3-vl-8b",
    "visionModel": "qwen3-vl-8b"
  },
  "features": { "chat": true, "guide": true, "inspect": true },
  "privacy": { "screenshots": "window", "denyApps": ["1cv8", "iBank2"] },
  "presence": { "url": "https://pushik.corp.local", "secret": "длинный-секрет-регистрации" }
}
```

| Поле | Что значит |
|---|---|
| `org` | Название, которое видно в настройках |
| `ai` | Сервер модели. `null` — ИИ выключен, работают только уроки |
| `ai.kind` | `openai` — vLLM, LiteLLM и любой OpenAI-совместимый сервер; `ollama` — Ollama |
| `ai.url` | Только `https`. `http` разрешён для `localhost` или с `"allowHttp": true` |
| `ai.model`, `ai.visionModel` | Модель для текста и для снимков экрана (если одна — `visionModel` можно не писать) |
| `ai.apiKey` | Ключ сервера, если он нужен. Файл читают все пользователи компьютера, поэтому лучше сервер без ключа во внутренней сети; токен на устройство — задача E-06 |
| `features.chat` | Чат с котом |
| `features.guide` | Показ по шагам («Сказать задачу», «Покажи, как») |
| `features.inspect` | «Объясни, что это» |
| `privacy.screenshots` | `screen` — весь экран (по умолчанию); `window` — ИИ видит только окно, с которым работает человек, остальное закрашено чёрным; `off` — снимок экрана не отправляется вообще, ИИ получает только названия кнопок окна от Windows. Непонятное значение считается `off` |
| `presence.url` | Сервер присутствия ([server/README.md](../../server/README.md)): админ-панель видит, кто из котов бодрствует, дремлет или спит. Только `https` (как у `ai.url`) |
| `presence.secret` | Секрет регистрации, от 16 знаков. По нему Пушик один раз получает свой токен, дальше ходит с токеном. Без `presence` Пушик никуда о себе не сообщает |
| `privacy.denyApps` | Программы (имя процесса), при которых Пушик на экран не смотрит: банк-клиент, кадровая 1С, СКЗИ |

Всегда, и без политики, Пушик не смотрит на экран, когда вводится пароль (поле пароля в фокусе),
открыт менеджер паролей (KeePass, 1Password, Bitwarden и другие), окно запроса прав администратора или экран входа.
Снимки дальше компьютера в этих случаях не уходят, человек видит объяснение.

## Групповая политика (Windows)

Ключ `HKLM\Software\Policies\Pushik`. Значения из реестра главнее файла.

| Значение | Тип | Пример |
|---|---|---|
| `Org` | REG_SZ | `Отдел ИБ` |
| `AiUrl` | REG_SZ | `https://llm.corp.local/v1` |
| `AiModel` | REG_SZ | `qwen3-vl-8b` |
| `AiVisionModel` | REG_SZ | `qwen3-vl-8b` |
| `AiKind` | REG_SZ | `openai` или `ollama` |
| `AiAllowHttp` | REG_DWORD | `1` |
| `AiOff` | REG_DWORD | `1` — ИИ выключен |
| `Chat`, `Guide`, `Inspect` | REG_DWORD | `0` — выключить |
| `Screenshots` | REG_SZ | `screen`, `window` или `off` |
| `DenyApps` | REG_SZ | `1cv8; iBank2` |
| `PresenceUrl` | REG_SZ | `https://pushik.corp.local` |
| `PresenceSecret` | REG_SZ | секрет регистрации |
| `PresenceAllowHttp` | REG_DWORD | `1` |

## Что Пушик сообщает серверу присутствия

Только состояние: бодрствует, дремлет (5 минут без мыши и клавиатуры), спит (с причиной:
экран заблокирован, сон, Пушик выключен, выход из системы, выключение), сколько секунд нет
действий, версию. При регистрации — ещё имя компьютера, пользователя и версию ОС.
Снимков, текста, названий окон и программ сервер не получает. Ключ устройства — хеш
от GUID машины и SID пользователя, сами GUID и SID не отправляются.

## Сертификат внутреннего сервера

Запросы к модели идут через сеть Chromium, она проверяет сертификат по системному хранилищу.
Корневой сертификат организации достаточно установить в «Доверенные корневые центры сертификации»
(обычно это уже сделано групповой политикой), отдельной настройки в Пушике не нужно.

## Тихая установка

```
"Пушик Setup 0.9.0.exe" /S
```

Перед установкой или после неё положите `policy.json` в `%ProgramData%\Pushik\` (GPO «Файлы», KSC или SCCM)
либо задайте значения в `HKLM\Software\Policies\Pushik`. Политика читается при запуске Пушика.
Установка идёт в профиль пользователя и не требует прав администратора.
