# План: корпоративный Пушик для отдела ИБ

Ветка: `enterprise`. Вся разработка корпоративной версии идёт здесь; в `master` уходит по готовности этапа.
Основа плана: отчёт «Пушик для отдела кибербезопасности» (`/mnt/project-files/research/reports/`).

Как отмечать: `[ ]` не начато, `[~]` в работе, `[x]` сделано. Рядом с готовым пунктом пишем коммит.
Правило: обычный Пушик для новичков продолжает работать как раньше, без ИИ и без сервера. Корпоративное включается конфигурацией.

## Этап 0. Корпоративная сборка (P0)

Цель: сборку можно ставить на рабочий компьютер отдела и проверять антивирусом/EDR.
