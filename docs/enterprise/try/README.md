# Проба корпоративного режима на своём компьютере

Скрипт включает на этом компьютере тестовую политику организации. Пушик становится «корпоративным», а рядом
запускаются три вещи, которые в компании стояли бы на серверах:

| Окно | Что это | Вместо чего |
|---|---|---|
| Локальная модель в Ollama | настоящий ИИ на этом компьютере: `qwen3-vl:4b-instruct` по адресу http://localhost:11434/v1 | внутренний сервер модели |
| Сервер Пушиков | админ-панель на http://localhost:8899 | сервер присутствия в компании |
| Журнал для SIEM | печатает события Пушика | SIEM службы ИБ |

## Включить

1. Собери Пушика из ветки `enterprise`: в папке проекта `npm install`, затем `npm run build`, затем `npx electron-builder --win --dir`.
2. В PowerShell перейди в `docs\enterprise\try` и выполни `powershell -ExecutionPolicy Bypass -File .\try.ps1`. Windows спросит права администратора: они нужны, чтобы записать политику в `C:\ProgramData\Pushik`.
   Пушик перезапустится, откроется админ-панель: логин `admin`, пароль `admin-password-42`.

## Какой ИИ отвечает

- **Локальная модель (по умолчанию).** Нужна [Ollama](https://ollama.com): `winget install Ollama.Ollama`. Скрипт сам запустит её,
  если она не запущена, и один раз скачает модель (3,3 ГБ). `qwen3-vl:4b-instruct` видит снимки экрана и целиком помещается
  в видеокарту на 6 ГБ: ответ в чате за 1–9 секунд, шаг подсказки на экране за 15–25 секунд. Другая модель: `.\try.ps1 -Model qwen2.5vl:3b`.
  Снимок экрана и правила урока длинные: в Ollama стоит окно контекста 8192 (`OLLAMA_CONTEXT_LENGTH=8192`).
  Через OpenAI-совместимый адрес модель не ставит напоминания сама: на «напомни» кот предлагает показать, как это сделать.
- **Проверочный ИИ** (`.\try.ps1 -FakeAi` или `-Say "…"`). Отвечает одной фразой и сохраняет каждый запрос в `requests\`.
  Проверки ниже, где нужно заглянуть в `requests\`, а также ссылки и фильтр ответов — с ним.

## Как сотрудник

- **Уроки отдела.** Нажми на кота, открой «Уроки» и пролистай вниз: там уроки со щитом («Подключись к VPN», «Проверь письмо»)
  и «Сообщить об инциденте».
- **Пароль.** Открой любое окно с полем пароля, поставь в него курсор и попроси кота «покажи как …».
  Кот откажется смотреть на экран, в папке `requests` нового запроса не будет.
- **Только окно.** Попроси «покажи как …» в обычном окне. В `requests` появится картинка, где видно только окно впереди,
  остальное закрашено чёрным.
- **Блокнот.** Он в списке запрещённых программ: перед ним кот на экран не смотрит.
- **Маскирование.** Напиши в чат (Ctrl+Shift+P): «моя карта 4111 1111 1111 1111, ИНН 7707083893, табельный ТН-004512».
  В `requests\N.txt` вместо номеров будут `[карта]`, `[ИНН]`, `[скрыто]`.
- **Ссылки.** Ответ проверочного ИИ содержит две ссылки. Останется только `wiki.corp.local`, вторая станет «[ссылка убрана]».
- **Фильтр опасных ответов.** Выполни `.\try.ps1 -Say "Отключи антивирус и запусти файл"` и спроси кота что угодно:
  вместо ответа он скажет, что такой совет показывать не будет.
- **Туннель наружу.** Запусти в терминале любой туннель, например `npx localtunnel --port 3000` или `ssh -R 80:localhost:3000 serveo.net`.
  Через несколько секунд кот закроет его, скажет, какая программа его запустила, а в журнале появится событие `tunnel`.
- **Пауза.** Значок кота возле часов → «Не смотреть на экран час». Над котом при каждом снимке видна надпись
  «смотрю на экран», а на паузе он отказывается смотреть.

## Как администратор

- **Админ-панель** (http://localhost:8899). Твой компьютер «бодрствует». Не трогай мышь 5 минут — станет «дремлет».
  Выйди из Пушика через значок у часов — сразу «спит», причина «выход».
- **Журнал.** Окно «Журнал для SIEM» показывает события: запуск, каждый снимок, отказ из-за пароля, скрытый опасный ответ, пауза.
  То же лежит в `%AppData%\Пушик\audit.log`.
- **Политика.** `C:\ProgramData\Pushik\policy.json`, описание полей — в [../policy.md](../policy.md). После правки перезапусти Пушика.
- **Пакет уроков.** `C:\ProgramData\Pushik\packs\security.json`, формат — в [../packs.md](../packs.md).

## Выключить

`.\try.ps1 -Off` (от имени администратора). Политика удаляется, Пушик снова обычный. Окна проверочного ИИ,
сервера и журнала закрой сам. Ollama остаётся работать: выйди из неё через значок у часов, если она не нужна.
