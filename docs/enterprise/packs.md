# Ролевые пакеты

Пакет — это JSON-файл, который подстраивает Пушика под работу отдела: свои уроки,
правила для ИИ и пояснения к служебным окнам (антивирус, DLP). Пакеты читаются
**только в корпоративном режиме**, то есть когда на компьютере есть политика
(см. [policy.md](policy.md)).

## Где лежат

Рядом с политикой, в папке `packs`:

| Система | Папка |
|---|---|
| Windows | `%ProgramData%\Pushik\packs\*.json` |
| macOS | `/Library/Application Support/Pushik/packs/*.json` |
| Linux | `/etc/pushik/packs/*.json` |

Писать в папку должен только администратор. На Windows у `%ProgramData%` по умолчанию
обычные пользователи могут создавать файлы, поэтому при установке закройте папку
`Pushik` правами (например, `icacls "%ProgramData%\Pushik" /inheritance:r /grant:r SYSTEM:(OI)(CI)F Administrators:(OI)(CI)F Users:(OI)(CI)RX`).

Пакеты читаются при запуске Пушика. Можно положить несколько; их уроки идут в «Уроках»
после встроенных, со значком щита.

## Формат

```json
{
  "id": "security",
  "title": { "ru": "Безопасность для сотрудника", "en": "Security for employees" },
  "version": 1,
  "prompt": "Правила для ИИ на английском или русском, до 2000 знаков.",
  "lessons": [ ... ],
  "explain": [ ... ]
}
```

- `id` — латиница в нижнем регистре, цифры и дефис, до 40 знаков. Два пакета с одним `id`
  не грузятся: берётся первый по имени файла.
- `title` — строка или `{ "ru", "en" }`.
- `prompt` — добавка к системной подсказке ИИ в чате, в показе на экране и в «Объясни, что это».
  Встроенные правила (не просить пароли и коды) она не отменяет.

### Урок

```json
{
  "id": "vpn",
  "title": { "ru": "Подключись к VPN", "en": "Connect to the VPN" },
  "words": "подключись к впн vpn",
  "match": "\\bvpn\\b|впн",
  "goal": "Connect to the company VPN in Windows settings",
  "steps": [
    { "say": "Нажми «Открой за меня», и я открою настройки VPN.", "open": "ms-settings:network-vpn" },
    { "say": "Нажми «Подключить».", "find": { "name": "^(Подключить|Connect)$", "types": ["Button"] }, "wait": "gone" }
  ],
  "done": "Готово!"
}
```

- `match` — регулярное выражение: какие слова в голосовой или текстовой задаче запускают урок.
  Пусто — урок запускается только из списка. Уроки пакетов проверяются раньше встроенных.
- `words` — слова для офлайн-распознавания речи.
- `goal` — цель для ИИ. Урок без `steps` целиком ведёт ИИ по снимку экрана. Урок со
  `steps` и `goal` показывает на каждом шаге кнопку «Покажи по экрану»: если нужную кнопку
  не нашли, ИИ покажет путь сам. Без ИИ работают только `steps`.
- `done` — что сказать в конце.

Шаг:

| Поле | Что значит |
|---|---|
| `say` | Что кот говорит, до 160 знаков. Одно действие. |
| `app` | Имя программы (`outlook`, `msedge`): кнопку ищем только в её окне. |
| `find.name` | Регулярка по имени элемента, как его видит система (UI Automation / доступность macOS). |
| `find.types` | `Button`, `MenuItem`, `ListItem`, `TreeItem`, `TabItem`, `Edit`, `CheckBox`, `RadioButton`, `Hyperlink`, `ComboBox`, `Text`, `Image`, `SplitButton`. |
| `find.scope` | `top` (окно сверху, по умолчанию), `taskbar`, `start`, `proc:<регулярка>`. |
| `wait` | Когда шаг сделан: `manual` (кнопкой, по умолчанию без `find`), `next` (появилась кнопка следующего шага, по умолчанию с `find`), `gone` (кнопка пропала), `focus` (курсор в поле), `titleChange` (сменился заголовок окна), `{ "top": "регулярка программы" }`. |
| `open` | «Открой за меня»: только `ms-settings:…` или `https://…`. Файлы и команды запрещены. |
| `hint` | Пояснение под шагом, до 400 знаков. |

Имя элемента удобно узнать в «Объясни, что это» (Пушик показывает, что сообщает система)
или в Accessibility Insights / Inspect.exe.

### Пояснение к окну

```json
{ "proc": "^(avp|avpui)$", "title": "", "text": "Это антивирус Касперского…" }
```

Когда человек нажимает «Объясни, что это» на окне, у которого программа совпала с `proc`
и заголовок — с `title` (нужно хотя бы одно), ИИ пересказывает `text` простыми словами.

### Сообщить об инциденте

```json
"report": {
  "title": { "ru": "Сообщить об инциденте", "en": "Report an incident" },
  "intro": "Не выключай компьютер и не удаляй письмо…",
  "to": "security@company.example",
  "questions": [
    { "ask": "Что случилось?", "options": ["Открыл(а) подозрительное письмо", "Антивирус что-то нашёл"] },
    "Как с тобой быстро связаться?"
  ]
}
```

Пушик задаёт вопросы по одному: ответ кнопкой из `options` (до 6, до 60 знаков) или своими словами.
В конце показывает текст с временем, именем компьютера и ответами. Его можно скопировать
или открыть черновиком письма на `to`. **Сам Пушик ничего не отправляет.** Отчёт открывается
из «Уроков» или словами «инцидент», «взлом», «заражение». До 12 вопросов.

## Ограничения и проверка

- До 10 пакетов, 30 уроков в пакете, 20 шагов в уроке, 50 пояснений, файл до 256 КБ.
- Регулярки до 200 знаков, без обратных ссылок и вложенных кванторов вида `(a+)+`.
- Ошибка в пакете — пакет пропускается целиком, остальные работают. Причина пишется
  в журнал Пушика (`pack: …`), человеку ничего не показывается.

Пример: [packs/security.json](packs/security.json) — фишинг, блокировка экрана, VPN,
шифрование диска, пояснения к Защитнику Windows, Касперскому и DLP.
