# Пушик

<img src="docs/pushik.gif" alt="Пушик" width="128" />

Пиксельный кот на рабочем столе, который показывает лапкой, куда нажать.
Windows и macOS.

</div>

## Что это

Пушик живёт поверх всех окон: ходит по краям окон, спит, умывается, следит за мышкой. Клики по пустому месту проходят сквозь него.

Ещё он учит пользоваться компьютером. Кот находит нужную кнопку на твоём экране и показывает её лапкой. Нажимаешь ты сам: кот никогда не нажимает за тебя. Когда шаг сделан, кот замечает это сам.

## Как с ним обращаться

| Что сделать | Что будет |
|---|---|
| Правой кнопкой по коту | окно «Чем тебе помочь?»: уроки, задача голосом или текстом, «Объясни, что это», настройки |
| Левой кнопкой по коту | кот шипит или ложится батоном |
| Два раза левой кнопкой или провести мышкой по коту | погладить: мурчит |
| Нажать на кота и потащить | несёшь за шкирку, отпустишь — упадёт на лапы |
| Отнести кота в Корзину | спрячется; вернуть — значком кота у часов |
| Значок кота у часов (в трее) | «Помоги мне», тренировка мышки, позвать кота, настройки, автозапуск, спрятать или показать, выход |

При первом запуске кот проводит тренировку мышки.

## Установка

1. Открой [последнюю версию](https://github.com/prettyw1ld/Pushik/releases/latest).
2. В разделе Assets скачай установщик:
   - Windows — `Pushik-Setup-….exe`;
   - Mac с чипом M (Apple Silicon) — `Pushik-…-arm64.dmg`;
   - Mac с процессором Intel — `Pushik-…-x64.dmg`.
3. Запусти его.
   - **Windows.** Если появится «Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае». Программа не подписана.
   - **Mac.** Перетащи Пушика в «Программы». Если Mac не даёт открыть, зайди в «Системные настройки → Конфиденциальность и безопасность» и нажми «Всё равно открыть». Там же разреши Пушику «Универсальный доступ», а для подсказок с ИИ ещё и «Запись экрана».

**Обновить:** закрой кота (значок у часов → «Выход»), скачай новый установщик и запусти поверх старой версии. Настройки сохраняются.

**Удалить:** Windows — «Параметры → Приложения → Пушик → Удалить». Mac — перетащи Пушика из «Программ» в Корзину.

## Что умеет

**Уроки** (без интернета и без ИИ). Кот находит кнопки через системную «доступность»: UI Automation на Windows, Accessibility на Mac. Снимки экрана для уроков не нужны.

- Тренировка мышки
- Обзор компьютера
- Сделать звук громче
- Сделать буквы крупнее
- Найти в интернете
- Позвонить по видео (WhatsApp)
- Посмотреть фото с флешки
- Папки, файлы и поиск
- Найти скачанный файл
- Открыть свой документ

**Защита от мошенников** (без интернета). Если запустилась программа удалённого доступа (AnyDesk, TeamViewer, RustDesk, Быстрая помощь Windows и другие), кот спрашивает, не звонит ли кто-то с указаниями. Ответ «Нет, это свои» отключает вопрос для этой программы.

**Задача своими словами.** Голос распознаётся на компьютере через Vosk (русская модель, без интернета). Если ИИ подключён, кот понимает любую задачу и ищет нужную кнопку по снимку экрана. Перед первым снимком он спрашивает разрешения.

**Позвать по имени** (выключено, включается в настройках). Скажи «Пушик» и сразу или после паузы попроси, что нужно: «Пушик, как отправить фото внуку?». Кот отвечает в чате, а если просьба про то, как что-то сделать, показывает на экране. Имя и просьбу кот распознаёт сам через Vosk, звук никуда не уходит. Дальше всё как при наборе в чате: в ИИ идёт текст просьбы, а для показа на экране, как обычно, уменьшенный снимок экрана после разрешения. Пока кот слушает, над ним виден значок микрофона. Если кота переименовали, он откликается на новое имя. Модель знает около 250 тысяч слов, и большинство кошачьих имён (Барсик, Мурзик, Снежок) среди них есть. Если имени нет (как «Пушик»), кот ждёт похожие на слух слова («пушок», «пушки»…) и на них тоже может откликнуться. Если похожих слов нет, кот говорит, что такое имя ему трудно расслышать.

**Имя кота.** По умолчанию Пушик (Pushik), в настройках можно дать своё. Новое имя видно в чате, облачках, меню у значка в трее, уведомлениях, и его знает ИИ. По-русски имя склоняется: «Спросить Барсика», «Чат с Барсиком». В системных подсказках про разрешения (Универсальный доступ, Запись экрана) остаётся «Пушик», потому что так приложение называется в системе.

**«Объясни, что это»** (нужен ИИ). Обведи непонятное место на экране, и кот объяснит, что это. После объяснения может предложить безопасно попробовать.

**Чат** (нужен ИИ). Вопросы, помощь с текстом, напоминания («напомни через 20 минут позвонить маме»).

**Настройки:** твоё имя и имя кота, окрас кота (белый, рыжий, чёрный), цвет окошек, размер кота и окон, звуки, чтение подсказок вслух, отклик на имя кота, запуск вместе с компьютером, модель ИИ и ключ.

## ИИ (по желанию)

Уроки, защита от мошенников и офлайн-голос работают без ИИ. Чтобы включить ИИ: правой кнопкой по коту → «Настройки» → «Помощник с ИИ», выбери модель и вставь ключ. Ключ хранится зашифрованным средствами системы (`safeStorage`).

| Модель в настройках | Чат | Экран | Ключ |
|---|---|---|---|
| Groq (по умолчанию) | `openai/gpt-oss-120b` | `qwen/qwen3.8-27b` | [console.groq.com](https://console.groq.com) → API Keys, бесплатно |
| DeepSeek Flash | `deepseek-flash` | `deepseek-flash` | [platform.deepseek.com](https://platform.deepseek.com) |
| Qwen Flash | `qwen3.8-flash` | `qwen3.8-flash` | Alibaba Cloud Model Studio, регион Singapore |

- Распознавание голоса через Whisper (`whisper-large-v3`) идёт через Groq. Без ключа Groq работает офлайн-голос Vosk.
- В `team.json` (см. ниже) можно также указать `claude`, `openrouter`, `ollama` или любой OpenAI-совместимый сервис (`"provider": "openai"` и `"aiUrl"`).

### Что уходит в ИИ

Снимки экрана делаются в память и не сохраняются на диск. Самого кота на снимке нет.

- **Задача своими словами:** снимок основного экрана, уменьшенный до 1024 px в ширину, и текст задачи.
- **«Объясни, что это»:** выделенный кусок (мелкий увеличивается до 4 раз), снимок окна с выделением в красной рамке (до 1280 px в ширину; если окно не определилось, весь экран) и название программы и элемента от системы.

## Для разработчиков

Нужен [Node.js](https://nodejs.org) 22.18 или новее. На Mac для сборки помощника `src/native/locator.swift` нужны Command Line Tools.

```bash
git clone https://github.com/prettyw1ld/Pushik.git
cd Pushik
npm install         # также скачивает офлайн-модель голоса (~40 МБ) в assets/vosk/
npm start           # собрать в build/ и запустить
```

| Команда | Что делает |
|---|---|
| `npm run build` | собрать в `build/` |
| `npm run watch` | пересобирать при изменениях |
| `npm run typecheck` | проверить типы |
| `npm test` | тесты из `test/` (happy-dom, `node --test`) |
| `npm run dist:win` | установщик Windows в `dist/` |
| `npm run dist:mac` | `.dmg` в `dist/` (только на Mac) |

### Выпуск версии

Установщики для Releases собирает GitHub Actions (`.github/workflows/release.yml`) по тегу `v*`: `.dmg` для arm64 и x64 на macOS, `.exe` на Windows. Mac-приложение подписывается ad-hoc (`tools/after-pack.cjs`), сертификата Apple нет.

```bash
# версия в package.json должна совпадать с тегом
git tag v0.9.0 && git push origin v0.9.0
```

Получается черновик релиза. Проверь его на странице Releases и нажми Publish. Тег с дефисом (`v1.0.0-beta.1`) публикуется как pre-release и не становится «последней версией».

### Отладка в браузере

`build/renderer/index.html` после `npm run build` открывается в браузере с тестовым рабочим столом. Параметры адреса: `?onboarded` (без тренировки мышки), `?color=white|ginger|black`, `?ai`, `?lang=en`, `?platform=darwin`.

### Ключи для команды (`team.json`)

Скопируй `team.example.json` в `team.json` и впиши нужные ключи:

```json
{
  "provider": "groq",
  "groqKey": "gsk_…",
  "deepseekKey": "",
  "qwenKey": "",
  "voice": "whisper"
}
```

`provider` — модель, включённая сразу. Пустой ключ значит, что модели нет. `team.json` в `.gitignore`, но если он лежит рядом при `npm run dist`, он попадает в установщик. Такой установщик не выкладывай в открытый доступ.

### Структура

| Папка | Что внутри |
|---|---|
| `src/main/` | главный процесс: окно поверх всех, трей, настройки, напоминания, автозапуск, IPC (`ipc.ts`) |
| `src/main/ai/` | запросы к ИИ (`guide.ts`, `llm.ts`, `providers.ts`), снимки экрана, голос (`stt.ts`) |
| `src/main/system/` | поиск кнопок (`locate.ts`), окна, файлы, программы удалённого доступа |
| `src/native/` | помощник Accessibility для Mac на Swift |
| `src/preload/preload.ts` | единственный мост между окном и главным процессом (`window.pushik`) |
| `src/shared/` | общие типы (`types.ts`) и тексты на русском и английском (`i18n.ts`) |
| `src/renderer/` | окно кота: `cat/` анимации, `guide/` уроки и подсказки, `panels/` окна, `ui/` |
| `test/` | тесты |
| `tools/` | сборка, сборка Swift-помощника, скачивание модели Vosk |

Стек: Electron 33, TypeScript без фреймворков, esbuild, PowerShell + UI Automation (Windows), Swift + Accessibility (macOS), Vosk (WebAssembly).
