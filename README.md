## Проблема

Бабушке нужно позвонить внуку по видео, сделать текст покрупнее или найти скачанный файл. Инструкция ей не поможет: в ней слова «панель задач», «Проводник», «контекстное меню», а на экране всё выглядит не так, как на картинке. Позвонить родным, чтобы объяснили, неудобно, и через неделю всё забудется.

Людей, которые впервые сели за компьютер в 60+, очень много. Им нужна не инструкция, а кто-то рядом, кто покажет пальцем.

## Решение

**Пушик это кот, который живёт поверх всех окон и показывает лапкой, куда нажать.** Он не говорит терминами, не открывает справку и **ничего не нажимает сам**: нажимает человек, поэтому он и учится.

- Кот подходит к нужной кнопке на **настоящем экране**, машет на неё лапкой, обводит рамкой и говорит подсказку вслух.
- Одна подсказка это одно действие, не больше 12 простых слов.
- Кот **сам видит**, что шаг сделан (открылось окно, появилась кнопка, стало громче), радуется и ведёт дальше. Нажимать «Далее» не нужно.
- Если человек потерялся, кот объяснит, что на экране и что сейчас произошло.

## Что умеет

### Уроки, которые проверяют себя сами
Все обучалки в одном месте, от простого к сложному, с прогрессом:

| Урок | Что человек научится делать |
|---|---|
| Мышка | нажать, нажать два раза, перетащить (тренировка при первом запуске) |
| Обзор компьютера | рабочий стол, «Пуск», панель задач, часы и звук, крестик у окна |
| Звук громче | кот сам замечает, что громкость изменилась |
| Буквы крупнее | найти настройку размера текста |
| Поиск в интернете | открыть браузер и найти что-то |
| Звонок по видео | позвонить через WhatsApp |
| Фото с флешки | кот сам замечает вставленную флешку |
| Файлы и папки | Проводник на Windows, Finder на Mac |
| Где мои загрузки | найти скачанный файл |
| Открыть свой документ | кот помогает найти и открыть нужный файл |

**Уроки работают без интернета и без ИИ.** Нужные кнопки кот находит через системную «доступность»: UI Automation на Windows и Accessibility на Mac. Поэтому он знает, где «Пуск», адресная строка браузера или флешка в Проводнике, не делая снимков экрана.

### «Объясни, что это»
Человек обводит непонятное место на экране, и кот объясняет, что это и зачем. Он же предупреждает об опасном: форма с данными карты, скачивание `.exe`, баннер «ваш ПК заражён». В ИИ отправляется **только выделенный кусочек**, а не весь экран. Если кот не уверен, он так и говорит.

### Задача своими словами
Большая кнопка «Сказать задачу»: «хочу позвонить внуку», «сделай звук громче». Голос распознаётся **прямо на компьютере** через Vosk, без интернета. Если подключён ИИ, кот понимает любую фразу (Whisper) и сам ищет на экране, куда показать.

### Учиться не страшно
- **«Проще»**: кот перескажет подсказку ещё проще.
- **«Попробовать самому»**: кот прячет подсказку и только проверяет.
- **«Что сейчас произошло?»**: кот объясняет, что изменилось на экране.
- **Домик навыков**: за каждое умение в комнате кота появляется вещь. За первый успех человек получает открытку, её можно сохранить и отправить внукам.

### Кот, а не робот
Три окраса, 66 пиксельных анимаций: гуляет по краям окон, спит, умывается, играет с клубком, мурчит, если погладить. Иногда следит за мышкой: плавно поворачивает голову за курсором, от анфаса до трёх четвертей, моргает и виляет хвостом, а если курсор шевелится у самой морды, бьёт по нему лапкой. Занятия меняет спокойно, раз в 10–20 секунд. Всегда поверх окон, но клики по пустому месту проходят насквозь и не мешают работать.

## Чем это лучше инструкции

| Обычно | С Пушиком |
|---|---|
| Читаешь инструкцию с терминами | Кот показывает лапкой на твоём экране |
| Картинка в инструкции не совпадает с экраном | Кот находит кнопку там, где она у тебя |
| Сам решаешь, получилось или нет | Кот сам видит, что шаг сделан |
| Без интернета ничего | Уроки и голос работают офлайн |
| За тебя нажимают, ты не учишься | Кот никогда не нажимает сам |

## Как мы используем ИИ

ИИ здесь **бонус, а не основа**: всё главное работает без него.

- **Зрение**: понять незнакомый экран, объяснить выделенный кусок, найти кнопку для свободной задачи.
- **Чат**: пересказать проще, ответить на вопрос.
- **Голос** (Groq Whisper): свободная речь вместо слов-команд.
- Если нужной модели у ключа нет, берётся похожая из доступных. Если лимит запросов кончился, кот говорит «Секундочку, я думаю…» и ждёт, а не показывает ошибку.
- Все ошибки переведены на человеческий язык: никаких «fetch failed».

### Какую модель выбрать

Модель выбирается в «Настройки → Помощник с ИИ» (или в `team.json`, см. ниже). У каждой модели свой ключ; ключи хранятся все сразу, поэтому переключаться можно без ввода заново.

| Модель | Чат | Экран (подсказки, «Объясни, что это») | Где взять ключ |
|---|---|---|---|
| **Groq** (по умолчанию) | `openai/gpt-oss-120b` | `qwen/qwen3.8-27b` | [console.groq.com](https://console.groq.com) → API Keys, бесплатно |
| **DeepSeek Flash** | `deepseek-flash` | `deepseek-flash` | [platform.deepseek.com](https://platform.deepseek.com) → API keys |
| **Qwen Flash** | `qwen3.8-flash` | `qwen3.8-flash` | Alibaba Cloud Model Studio, регион Singapore → API Key |

- DeepSeek Flash (DeepSeek-V4.1-Flash) и Qwen 3.8 Flash понимают и текст, и картинки, поэтому одна модель делает всё. У Groq лучший бесплатный текст и лучшее зрение — это две разные модели.
- «Размышления» перед ответом (thinking) у DeepSeek и Qwen выключены: кот их не показывает, а ждать пришлось бы в разы дольше.
- Голос через Whisper есть только у Groq. Если в настройках выбран DeepSeek или Qwen, а ключ Groq тоже вписан, голос продолжает работать через Groq. Без ключа Groq работает встроенный офлайн-голос (Vosk).
- Qwen подключается к международному региону Model Studio (`dashscope-intl.aliyuncs.com`). Ключ из пекинского региона там не подойдёт: тогда в `team.json` нужен свой адрес, `"aiUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1"`.
- Ещё можно Claude (`"provider": "claude"`), OpenRouter или любой OpenAI-совместимый сервис (`"provider": "openai"` и `"aiUrl"`), а также локальную Ollama. Эти варианты задаются только в `team.json`.

## Как кот смотрит на экран

Есть три способа, и только два из них используют ИИ.

**1. Уроки — без снимков и без ИИ, по координатам от системы.** Кот спрашивает у Windows (UI Automation) или macOS (Accessibility), какие кнопки и поля сейчас на экране. Система отдаёт их названия, типы и точные координаты. Кот находит нужное по названию и прыгает туда. Что шаг сделан, он тоже узнаёт у системы: какое окно сверху, появилась ли кнопка, изменилась ли громкость. Картинка экрана здесь вообще не нужна.

**2. «Задача своими словами» — по снимку всего экрана.** Кот делает снимок основного экрана в память (уменьшенный до 1024 пикселей в ширину; самого кота на снимке нет) и отправляет его модели вместе с задачей и уже данными подсказками. Модель возвращает фразу и рамку вокруг кнопки в пикселях снимка, а приложение пересчитывает рамку в координаты экрана. Туда кот прыгает и рисует кольцо. Пока человек выполняет шаг, кот раз в 1,2 секунды сравнивает крошечные снимки (160 пикселей): если поменялось больше 3% экрана, он делает новый снимок и проверяет, получилось ли.

**3. «Объясни, что это» — по снимку, но только выделенного кусочка.** Человек обводит мышкой кнопку или строку. Координаты рамки нужны только для того, чтобы вырезать этот кусок: кот делает снимок экрана в полном разрешении, вырезает выделенную область, мелкую увеличивает до 4 раз (чтобы модель прочла подпись) и отправляет модели **только этот кусок**. Весь экран и координаты модель не получает. Она сначала дословно читает подпись, потом объясняет простыми словами. Если не уверена, честно просит выделить точнее, а не гадает. Кольцо и лапка показывают на рамку, которую нарисовал сам человек. Кнопка «Проще» отправляет модели только текст объяснения, без картинки.

Снимки экрана живут только в памяти и никуда не сохраняются.

## Запуск

Нужен [Node.js](https://nodejs.org) 22.18 или новее.

```bash
git clone https://github.com/prettyw1ld/Desktop-Helper.git
cd Desktop-Helper
npm install      # заодно скачает офлайн-модель голоса (~40 МБ)
npm start        # собирает TypeScript в build/ и запускает
```

### Подключить ИИ (необязательно)
Проще всего вписать ключ прямо в приложении: «Настройки → Помощник с ИИ», выбрать модель и вставить ключ. Ключ шифруется средствами системы.

Чтобы новичку ничего не вводить, ключи кладёт команда: скопируйте `team.example.json` в `team.json` и впишите ключи тех моделей, которые нужны (хватит и одного):

```json
{
  "provider": "groq",
  "groqKey": "gsk_…",
  "deepseekKey": "sk-…",
  "qwenKey": "sk-…",
  "voice": "whisper"
}
```

`provider` — какая модель включена сразу: `groq`, `deepseek` или `qwen`. Пустой ключ значит «этой модели нет». Если человек выберет в настройках другую, его выбор сохраняется. Старый формат `{ "provider": "groq", "apiKey": "gsk_…" }` тоже работает.

`team.json` в `.gitignore`, в репозиторий он не попадает. Подробнее про Groq в [GROQ-SETUP.md](GROQ-SETUP.md).

### Установщик со значком на рабочем столе
```bash
npm run dist:win   # Windows: dist/Пушик Setup ….exe
npm run dist:mac   # macOS
```
Установщик кладёт ярлык на рабочий стол и в «Пуск». Если рядом лежит `team.json`, он попадает внутрь, поэтому такой установщик нельзя выкладывать в открытый доступ.

На macOS разрешите Пушику «Универсальный доступ», а для ИИ ещё и «Запись экрана».

## Как устроено

```
Человек ──► Кот (окно поверх всех) ──► Урок (scenarios.ts)
                     │                         │
                     │                ищет кнопку: locate.ts
                     │                (UI Automation / Accessibility)
                     │                         │
                     ▼                         ▼
             «Что произошло?»,        показывает лапкой ──► ждёт ──► проверяет сам
           «Объясни, что это»                                         (coach.ts)
                     │
                     ▼
   ИИ по желанию: guide.ts + llm.ts (Groq, DeepSeek или Qwen)
```

Код на TypeScript. Главный процесс и окно кота общаются через мост `src/preload/preload.ts`; все данные между ними описаны в `src/shared/types.ts`.

| Папка | Что внутри |
|---|---|
| `src/main/` | главный процесс: окно поверх всех, трей, настройки, напоминания, автозапуск, IPC |
| `src/main/ai/` | снимок экрана и подсказки ИИ (`guide.ts`), чат (`llm.ts`), модели и их адреса (`providers.ts`), голос (`stt.ts`), сеть (`http.ts`) |
| `src/main/system/` | поиск кнопок без ИИ (`locate.ts`), окна других программ, файлы, календарь |
| `src/native/` | помощник «доступности» для Mac на Swift |
| `src/shared/` | тексты на двух языках и общие типы |
| `src/renderer/cat/` | кот: анимации и поворот головы (`sprites.ts`), чем занят сам (`behaviour.ts`), слежка за курсором, позы |
| `src/renderer/guide/` | уроки (`scenarios.ts`, `coach.ts`), подсказки ИИ, «Объясни, что это», тренажёр мыши |
| `src/renderer/panels/` | окна: «Чем помочь?», уроки, чат, напоминания, настройки, голосовой ввод |
| `src/renderer/ui/`, `home/`, `input/` | облачко, рамка с клубком, иконки, домик навыков, мышь |
| `tools/` | сборка (`build.mts`), скачивание модели голоса, новые кадры кота (`make_extra_sprites.py`) |

Команды:
```bash
npm run build       # собрать в build/
npm run watch       # пересобирать при изменениях
npm run typecheck   # проверить типы
npm test            # тесты (test/)
```

Интерфейс открывается и в обычном браузере (`build/renderer/index.html` после `npm run build`) с ненастоящим рабочим столом для отладки: `?onboarded` пропускает тренировку мышки, `?color=white` меняет окрас.

## Стек
Electron 33, TypeScript без фреймворков (сборка esbuild), PowerShell и UI Automation (Windows), Swift и Accessibility API (macOS), Vosk (WebAssembly), Groq / DeepSeek / Qwen API (OpenAI-совместимые), Web Audio.
