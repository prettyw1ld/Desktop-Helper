## Проблема

Пожилые люди, дети, все, кто впервые сел за компьютер, не читают инструкций. Им непонятны слова «панель задач», «проводник» и «адресная строка». Видеоуроки идут слишком быстро. Если помогает родственник, он забирает мышку и делает всё сам, а человек так ничему и не учится. В итоге он боится нажать не туда и каждый раз зовёт на помощь.

## Решение

**Пушик** — живой пиксельный кот на рабочем столе. Он помогает **без инструкции**:

- **показывает, а не объясняет**: подходит к нужной кнопке, машет на неё лапкой, обводит рамкой и говорит одну короткую фразу без терминов;
- **никогда не нажимает сам**: нажимает человек, поэтому он запоминает действие руками;
- **сам замечает, что шаг сделан**: окно открылось, звук стал громче, появилась следующая кнопка. Тогда кот радуется и переходит к следующему шагу;
- **работает без ИИ, без интернета и без ключей**: нужные кнопки он находит через системную «доступность» Windows и macOS, а голос распознаёт прямо на компьютере;
- **не пугает**: кот живёт своей жизнью, мурчит, играет с клубком и спит. К нему хочется обратиться, а не закрыть его.

## Что умеет

### 1. Знакомство без инструкции
При первом запуске кот предлагает нажать на него, нажать два раза и перетащить. Это тренировка мышки, замаскированная под игру. Потом он проводит **обзор компьютера**: показывает лапкой «Пуск», панель задач, часы и звук, крестик у окна.

### 2. «Чем тебе помочь?»
Клик по коту открывает одно простое окно:
- 🎙 **«Сказать задачу»**: голосом, без интернета («хочу позвонить по видео», «фото с флешки»);
- ⌨️ поле, чтобы написать задачу своими словами;
- 😵 **«Я запутался»**: кот простыми словами говорит, какое окно сейчас открыто, и показывает, где его крестик;
- 🔍 **«Объясни, что это»**: человек обводит мышкой любую кнопку или строку, и кот объясняет, что это такое;
- **«Уроки»** и **«Настройки»**.

### 3. Уроки по шагам
Уроки идут от простого к сложному, и прогресс виден:

| Урок | Что делает кот |
|---|---|
| Мышка | нажать, нажать два раза, перетащить |
| Обзор компьютера | «Пуск», панель задач, часы, крестик |
| Звук громче | показывает значок звука и сам замечает, что стало громче |
| Буквы крупнее | ведёт к настройке размера текста |
| Найти в интернете | браузер → адресная строка → ввести запрос |
| Позвонить по видео | WhatsApp → контакт → кнопка видеозвонка |
| Фото с флешки | сам замечает вставленную флешку и ведёт к фотографиям |
| Помоги с файлами | учебная папка, «Загрузки», открыть свой документ |

Один шаг — одно действие, подсказка до 12 слов, кот читает её вслух. Если не получается, есть кнопки «Покажи ещё» и «Открой за меня». Клубок ниток катится от кота к нужной кнопке, чтобы взгляд не терялся.

### 4. «Объясни, что это»
Человек обводит мышкой незнакомую кнопку, значок или строку. Кот смотрит **только на обведённый кусочек** и объясняет его в одном-двух предложениях. Дальше можно нажать «Проще», «Попробовать самому», «Запомнить навык» или «Повторить». Если на картинке есть что-то опасное (данные карты, подозрительное скачивание, баннер «ваш ПК заражён»), кот предупреждает и не предлагает это нажимать.

### 5. «Кот учится у тебя»
Роли меняются: кот «забыл», как сделать задачу, и просит человека показать. Человек делает всё **сам, без подсказок**, а кот по снимку экрана проверяет, получилось ли. Так видно, что навык закрепился. Если не выходит, всегда можно попросить подсказку.

### 6. Домик освоенных навыков
Каждый освоенный навык становится предметом в уютной комнате Пушика: телефон за видеозвонок, рамка с фото за флешку, лупа исследователя за поиск, игрушечная мышка, печатная машинка. Нажмёшь на предмет, и кот напомнит навык или повторит урок. За первый успех человек получает **открытку**, которую можно сохранить в PNG и отправить родным.

### 7. Живой характер
Три окраса и 66 анимаций: ходит и бегает, запрыгивает на окна и катается на них, умывается, играет с клубком, зевает, спит. На двойной клик он мурчит, на пять быстрых кликов злится, а если его взять мышкой, висит за шкирку. Кот никогда не мешает: клики мимо него проходят сквозь его окно.

## Как устроено

```
 человек ──► голос (Vosk, офлайн) / текст / кнопка урока
                 │
                 ▼
         готовый сценарий урока ────────────────┐
                 │                              │ нет сценария?
                 ▼                              ▼
   поиск кнопки через «доступность» ОС     ИИ с зрением (бонус):
   UI Automation (Windows)                 снимок экрана только в памяти →
   Accessibility (macOS)                   «куда показать лапкой»
                 │                              │
                 └──────────► кот подходит, машет лапкой, рамка, голос
                                   │
                                   ▼
                    следит за экраном: шаг сделан? → следующий шаг
```

**Главное для оценки:**
- **Уроки работают без ИИ.** Каждый урок — это сценарий из шагов (`src/renderer/scenarios.js`). Кнопки находятся по их системным названиям, а не по картинке, поэтому кот ведёт точно и быстро даже без интернета.
- **ИИ — это бонус.** Если команда вписала ключ, кот понимает любые задачи словами, объясняет обведённые элементы и проверяет «Кот учится у тебя». По умолчанию используется Groq: `openai/gpt-oss-120b` для текста, `qwen/qwen3.8-27b` для зрения, Whisper для свободной речи.
- **Приватность.** Снимок экрана хранится только в памяти и на диск не пишется. Для «Объясни, что это» в модель уходит только обведённый кусочек экрана. Текст со снимка модель считает данными, а не командами.
- **Безопасность.** Кот не управляет мышкой и клавиатурой. Всё нажимает человек.

## Запуск

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
git clone https://github.com/prettyw1ld/Desktop-Helper.git
cd Desktop-Helper
npm install      # заодно скачает офлайн-модель голоса Vosk (~40 МБ)
npm start
```

**ИИ (необязательно).** Скопируй `team.example.json` в `team.json` и впиши бесплатный ключ с [console.groq.com](https://console.groq.com). Одного ключа хватает на чат, зрение и голос. Без `team.json` уроки, голос по командам и «Я запутался» работают как обычно. Ключи задаёт команда, а не пользователь: при сборке `team.json` попадает в установщик, и человеку ничего вводить не надо. Для настоящего продукта ключ нужно держать на своём сервере-посреднике.

**macOS.** Разрешите Пушику «Универсальный доступ», чтобы он видел кнопки, и «Запись экрана», если нужен ИИ.

**Установщик:** `npm run dist:win` или `npm run dist:mac`.

**Проверки:** `node --test tools/test-file-help.js`.
