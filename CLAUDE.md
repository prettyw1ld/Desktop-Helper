# Пушик

Десктопный кот-помощник на Electron 33 + TypeScript без фреймворков (сборка esbuild). Работает на Windows и macOS. Пользователи — в основном люди, которым трудно с компьютером, поэтому все тексты простые, без терминов.

## Команды

```bash
npm run typecheck   # типы: main, renderer и тесты (~5 с)
npm test            # собрать тесты и прогнать node --test (~10 с)
npm run build       # собрать приложение в build/
npm start           # запустить кота
```

После любых правок в `src/` или `test/` гоняй `npm run typecheck` и `npm test` и показывай вывод. Stop-хук в `.claude/settings.json` всё равно не даст закончить с красными проверками.

Кота на экране ты не видишь. Если менялось поведение, анимация или окно, прямо скажи, что именно надо проверить руками через `npm start`, и не пиши «работает», пока этого никто не проверил.

## Как устроено

- `src/main/` — главный процесс: окно поверх всех, трей, настройки, IPC (`ipc.ts`).
  - `ai/` — запросы к ИИ (Groq, DeepSeek, Qwen, Ollama), снимки экрана, голос.
  - `system/` — поиск кнопок через UI Automation (PowerShell) и Accessibility (Swift), окна, файлы.
- `src/preload/preload.ts` — единственный мост, окно видит его как `window.pushik`.
- `src/shared/` — общие типы (`types.ts`) и тексты на двух языках (`i18n.ts`).
- `src/renderer/` — окно кота: `cat/` анимации, `guide/` уроки и подсказки, `panels/` окна, `ui/`.
- `src/native/locator.swift` — помощник «доступности» для Mac.
- `test/` — тесты на happy-dom. `setup.ts` импортируется первым, `helpers.ts` даёт `resetDesk()` и тестовый рабочий стол.

## Правила

- Окно кота работает с `contextIsolation`, `sandbox`, без `nodeIntegration`. Это не трогаем. Никакого Node и `require` в `src/renderer/`.
- Новый вызов из окна в главный процесс добавляется в четыре места: тип в `PushikApi` (`shared/types.ts`), `preload.ts`, `ipcMain.handle` в `main/ipc.ts`, заглушка в `renderer/core/mock-api.ts`. Новое событие из главного процесса — ещё и в `PUSHIK_EVENTS`.
- Всё, что приходит из окна в `ipcMain`, считаем непроверенным: проверяем тип и формат, как в `open:uri` и `open:drive`.
- Кот никогда не нажимает за человека, только показывает. Снимки экрана не сохраняются на диск, в ИИ уходит только нужный кусок.
- Ключи ИИ: `team.json` в `.gitignore`, в настройках они шифруются через `safeStorage`. Ключи не логируем и не коммитим.
- Любой текст для человека — через `i18n.ts`, сразу на русском и английском.
- Код для одной платформы прячем за `process.platform`; вторая платформа должна продолжать работать.
- Коммиты в стиле Conventional Commits на английском, как в истории: `fix(guide): …`, `feat(cat): …`.
